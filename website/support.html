Support

Yardarm is free, open-source software maintained by its contributors. Here's how to get help and how to reach us.

Contact

  • Email — support@yardarmdev.com
  • GitHub issues — github.com/JJJ-Mo3/yardarm/issues (preferred for bugs and feature requests, so others can find the answer too)

Before you write in

Most questions are answered in the built-in resources:

  • The troubleshooting guide — including the macOS "Yardarm is damaged" fix, empty model dropdowns, and context-window errors.
  • The FAQ — accounts, privacy, local models, worktrees.
  • The documentation — install, setup, and every feature.
  • Inside the app, the help button beside the theme toggle (or Cmd+9) opens a built-in guide, FAQ, and troubleshooting section.

What to include in a bug report

  • Your Yardarm version and macOS version (Settings → About lists both).
  • The exact error text — Settings → About shows the bundled runtime's boot status and the full error if the agent fails to start; chat errors appear in the transcript.
  • What you were doing when it happened, and whether it happens every time.
  • Which model/provider was active (local models: include the server, e.g. Ollama, and the configured context length).

Requesting features

Open a GitHub issue describing the problem you're trying to solve. Pull requests are welcome too — see the repository's contributing notes.
